# 直播计划表模板编辑器

一个**零依赖、单文件**的网页小工具，内置三套可直接编辑的排期海报模板，改完文字、换好图片即可一键导出 PNG，适合直播预告、一周排班等场景。

- 模板 A · **竖版周预告**（1000 × 1450）：深蓝星轨布纹外框 + 白色内芯 + 星期「文件夹标签」凸起 + 手绘虚线框与皇冠/胶带/音符贴纸装饰
- 模板 B · **横版排班表**（1600 × 1072）：宋体品牌圆环 +「沐又双播」跨行大格 + 骑缝成员小圆章 + 云朵双线 logo + 青海波底纹
- 模板 C · **手帐撕纸周计划**（1080 × 1527）：木纹桌面 + 左缘撕纸锯齿 + 皱纸长尾夹 + 条纹头像徽章 + 三列手写排期 + 底部贴纸，支持 `?tpl=C` 直达

## 快速开始

无需构建、无需安装依赖，直接用浏览器打开即可：

```bash
# 方式一：直接打开
open index.html        # macOS
xdg-open index.html    # Linux

# 方式二：本地起个静态服务（推荐）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

> ⚠️ 导出 PNG 功能依赖 CDN 上的 `html2canvas`，需要联网。

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 多模板切换 | 工具栏顶部 Tab 一键切换 A / B / C 模板（URL 加 `?tpl=C` 可直达） |
| 所见即所得编辑 | 页面上所有文字（标题、日期、主播名、时间格、骑缝章、贴纸气泡等）点击即可直接修改 |
| 图片替换 | 顶部头图、主播头像、成员圆标、模板 C 的头像徽章与装饰贴纸点击即可上传本地图片替换 |
| 加盖「休」章 | 先点击选中一个格子，再点工具栏按钮，切换「休·调养」印章样式 |
| 自动保存 | 所有编辑内容和上传图片实时存入浏览器 `localStorage`，刷新不丢失 |
| 恢复占位 | 一键清空编辑，回到初始占位内容 |
| 导出 PNG | 以 2 倍分辨率（scale:2）渲染当前模板并下载高清图片 |

## 实现说明

- **单文件架构**：`index.html` 内含全部样式与脚本，无构建步骤，方便分发和二次修改。
- **原图级还原**：模板 A 的头图与 chibi 头像、模板 C 的整个手帐背景均直接取自 `demo/` 原图
  （C 的手写文字已擦除，由可编辑文字层原位覆盖），装饰与参考图像素一致；A/B/C 模板需与
  `demo/` 目录一同分发（页内相对路径引用）。
- **数据驱动渲染**：三套模板的行 / 格子由脚本按 `DEFAULTS` 数据结构生成（`renderA()` / `renderB()` / `renderC()`），
  修改占位内容只需改 `DEFAULTS`，或直接在页面上编辑。
- **编辑机制**：所有可编辑元素使用原生 `contenteditable`，`input` 事件触发时按 `data-k` 键写入
  `localStorage`；上传图片以 DataURL 形式一并持久化。
- **导出**：使用 [html2canvas](https://github.com/niklasvh/html2canvas) 将当前激活的模板节点渲染为
  Canvas，再通过 `toDataURL('image/png')` 触发下载。

## 自定义模板

1. **改默认内容**：编辑 `index.html` 中的 `const DEFAULTS = {...}`（主播行、成员圆标、日期、排班格）。
2. **改样式**：模板 A 的样式以 `.a-` 开头，模板 B 以 `.b-` 开头，均在文件顶部 `<style>` 区块内，
   主题色可通过修改对应 `color` / `background` 快速调整。
3. **新增模板**：复制一段 `.tpl` 结构 + 对应 CSS，新增一个 `renderD()`，并在 `switchTpl()` 中注册即可。
